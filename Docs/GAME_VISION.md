# Primal Frontier — Game Vision

## High Concept

**Primal Frontier** is an original first- and third-person open-world survival game set in **Eryndor**, a vast prehistoric-fantasy world fractured by unstable dimensional regions known as **Frontiers**.

Players begin as vulnerable survivors with primitive tools and a fragile shelter. Through exploration, hunting, crafting, settlement building, creature companionship, technology research, and dangerous expeditions, they grow into powerful dimensional explorers capable of mastering multiple Frontiers.

The game supports single-player and cooperative multiplayer, with architecture designed for server-authoritative play and eventual optional PvP.
