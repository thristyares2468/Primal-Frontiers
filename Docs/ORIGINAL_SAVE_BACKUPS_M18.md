`FPFSaveFileStore::PreserveOriginal(Slot, Edge, Error)` copies the selected highest valid A/B generation byte-for-byte to `Saved/Persistence/Originals/<Slot>/<Edge>.pfs`. Slot and edge are bounded ASCII identifiers, never arbitrary paths. New preservation requires the game thread and a healthy source pair; missing sources or any corrupt sibling refuse. Existing destinations are never replaced, including an invalid original or directory. Bounded reader/no-replace writer archives avoid platform CopyFile failure cleanup; our failure path retains partial destinations and blocks retry until explicit recovery. Exact bounded envelope/payload, generation and original UTC are verified after copy. No crash-atomic publication, cross-process race or authentication guarantee is made; future callers serialize trusted migration preparation.

Repeated calls validate and retain the FIRST original, even after normal A/B rotation. That existing-original result certifies its envelope only; future migration callers must separately read and semantically validate their source/world/owner/content edge before transforming or publishing. The original reader preserves output on refusal. The API does not restore a world, choose a semantic fallback, migrate records or grant source recovery permission.

`PF.Persistence.OriginalBackup` uses unique synthetic native slots and real files to test exact source bytes/generation/time, repetition/rotation, missing/corrupt/path-traversal/destination refusal and unchanged source/output. It cleans only its own explicit files; no private save/profile or recursive directory deletion. `PF.Persistence.FileGenerations` is the narrow ordinary-file-store regression. Build/test results will be recorded after execution. No saved level or manual fixture is required for this backend primitive.
