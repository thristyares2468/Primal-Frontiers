## Tests and reproduction

No authored level or user playtest required. Close Unreal before running from project root:

```powershell
.\Scripts\RunNativeAutomation.ps1 -TestFilter 'PF.Persistence.FrozenM8Records+PF.Persistence.FrozenM8Restore+PF.Persistence.CopperBackupFailure+PF.Persistence.SaveInspection' -Label M18FrozenWriter -TimeoutSeconds 180
```

`FrozenM8Records` verifies hashes/sizes, original schema and identity/attribute/batch/freshness/structure values, missing progression/chest-filter defaults, actual old file-envelope read and unchanged output/source on future/truncated candidate refusal. The good fixture is consumed as frozen bytes, never generated by the current encoder.

`FrozenM8Restore` installs only a unique disposable copy of that exact envelope into a native L_Automation world with matching named fixtures. Actual ConfigureStartup/ApplyStartup, owner login/restoration, repeated Load with unsaved extra wood, and normal separate-slot currentV2 Save/Load retain quantities/ownership/support/creature/spawner/pickup identities without duplication. Legacy load grants zero XP, knowledge, craft credit, gather windows or stat/tech points. Original source envelope remains byte exact with no second generation. Food ages using its original capture/file UTC; after respective181/91second thresholds, player/storage food must be absent rather than renewed. Tests require passing assertions, exact selectors, normal exit and clean logs. No authored map or personal save is used.
